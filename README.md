1. **Clone the repository:**

```bash

```

2. **Navigate to the folder:**

```bash

```

3. **Start reading:**
   Each topic has its own Markdown file. You can read them directly on GitHub, or open them in your editor. Start with
   `notes/01-basics.md` and go sequentially.
